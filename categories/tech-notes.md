# 📝 技术笔记

记录前端、后端、DevOps 等技术学习心得，分享深度技术文章。

## 前端开发

### [React Hooks 入门指南](/posts/react-hooks-guide)

React 16.8 引入了 Hooks，让函数组件拥有了类组件的能力。详解 useState、useEffect、useContext、useRef、useMemo、useCallback 等常用 Hooks，演示自定义 Hook 的封装方法。

### [Vue 3 组合式 API 入门](/posts/vue3-composition-api)

Vue 3 组合式 API 提供了更灵活的组件逻辑组织方式。详解 ref/reactive 响应式绑定、computed/watch 使用，演示组合式函数封装和 TypeScript 支持。

### [TypeScript 类型体操入门](/posts/typescript-type-gymnastics)

TypeScript 的类型系统非常强大。从 Partial、Pick、Omit 等基础工具类型，到条件类型、模板字面量、递归类型等进阶技巧，实战实现 ReturnType 和 Parameters。

### [CSS Grid 布局完全指南](/posts/css-grid-guide)

CSS Grid 是现代网页布局的强大工具。全面介绍网格定义、区域命名、项目定位、对齐方式，提供响应式卡片布局和圣杯布局两个实战案例。

### [前端性能优化实战](/posts/frontend-performance)

从加载性能、渲染性能、缓存策略三个维度介绍优化策略，详解 Core Web Vitals 监控指标和性能 API 使用方法。

### [前端安全防护指南](/posts/frontend-security-guide)

详解 XSS、CSRF、点击劫持等常见威胁的原理和防护措施，提供 CSP、HttpOnly Cookie、SRI 等安全配置示例。

### [VitePress 首页时间戳显示方案对比](/posts/vitepress-timestamp-approaches)

对比四种在 VitePress 首页显示「最近更新时间」的实现方案：Git lastUpdated、Vite define 注入、构建脚本生成、new Date() 直出，分析各自优劣和适用场景。

## 后端开发

### [Node.js 异步编程详解](/posts/nodejs-async-programming)

梳理异步编程从回调到 Promise 再到 async/await 的演进，详解并行执行策略，深入分析 Node.js 事件循环机制。

### [RESTful API 设计最佳实践](/posts/restful-api-design)

从 REST 基本原则出发，详解 URL 设计规范、HTTP 方法使用、状态码选择、统一响应格式，以及查询参数的最佳实践。

## DevOps

### [Docker 容器化部署实践](/posts/docker-deployment-guide)

从基础概念入手，详解 Dockerfile 编写技巧（包括多阶段构建），介绍 Docker Compose 多容器编排和生产环境最佳实践。

### [Git 工作流最佳实践](/posts/git-workflow)

介绍分支命名规范、Git Flow 和 GitHub Flow 工作流模式、Conventional Commits 提交规范，详解交互式变基、Cherry-pick、Stash 等高级命令。
