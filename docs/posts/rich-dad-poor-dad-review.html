《穷爸爸富爸爸》读书笔记 ​

《穷爸爸富爸爸》是罗伯特·清崎的经典财商教育书籍，这本书改变了我对金钱和财富的认知方式。

书籍概览 ​

信息内容
作者罗伯特·清崎（Robert Kiyosaki）
出版时间1997年
类型个人理财、财商教育
核心主题资产与负债的区别、财商培养、财务自由

核心观点 ​

两个爸爸的不同思维 ​

书中作者有两个"爸爸"：

对比项穷爸爸（亲生父亲）富爸爸（朋友父亲）
学历博士学位中学学历
职业政府官员、教师企业家、投资者
收入稳定工资多元收入来源
金钱观"钱是万恶之源""贫穷才是万恶之本"
教育观"好好读书，找份好工作""学会让钱为你工作"
风险观避免风险，求稳定管理风险，抓住机会
结局财务困境，依赖政府财务自由，财富传承

两种截然不同的金钱观，决定了截然不同的人生轨迹。

资产 vs 负债 ​

这是书中最重要的概念区分：

资产 = 能把钱放进你口袋的东西
负债 = 把钱从你口袋拿走的东西
1
2

真正的资产：

  • 不需要你到场就能正常运转的业务
  • 股票、债券、基金
  • 产生收入的房产（出租）
  • 专利、版权、知识产权
  • 有增值潜力的收藏品

常见的负债（很多人误以为是资产）：

  • 自住的房产（房贷、物业费、维修费）
  • 豪车（保养、保险、贬值）
  • 信用卡消费
  • 任何需要持续花钱维护的东西

富人买入资产，穷人只有支出，中产阶级买入他们以为是资产的负债。

现金流模式对比 ​

穷人的现金流：

收入（工资） → 支出（生活开销） → 0
1

中产阶级的现金流：

收入（工资） → 负债（房贷、车贷） → 支出 → 0
1

富人的现金流：

资产（投资） → 收入（被动收入） → 再投资 → 更多资产
            ↓
          支出（生活开销）
1
2
3

建立正向的现金流循环，让资产产生的收入覆盖支出，这是财务自由的基础。

六课核心内容 ​

第一课：富人不为钱工作 ​

大多数人工作的动机是恐惧（害怕没钱）和贪婪（想要更多钱）。富人则关注如何建立资产，让资产产生收入。

关键认知：

  • 工作是学习的机会，不只是赚钱的手段
  • 真正的财富是时间自由，不是金钱数量
  • 穷人和中产阶级为钱工作，富人让钱为他们工作

第二课：为什么要教授财务知识 ​

财富不是你赚多少钱，而是你能留住多少钱，以及这些钱能为你工作多久。

财务知识的重要性：

  • 读懂财务报表（资产负债表、收入支出表）
  • 理解现金流运作
  • 区分资产和负债
  • 很多高收入者因为缺乏财务知识而陷入债务

第三课：关注自己的事业 ​

工作（Job）和事业（Business）是不同的：

  • 工作 - 为别人打工，帮助老板实现梦想
  • 事业 - 建立自己的资产，实现财务自由

建议：

  • 保持现有工作，同时发展自己的事业
  • 在业余时间建立资产
  • 不要把职业和事业混淆

第四课：税收的历史和公司的力量 ​

了解税收制度和企业结构对财富积累的影响：

  • 公司可以合法节税
  • 富人利用公司结构保护资产
  • 税法对不同收入类型有不同税率
  • 学习法律知识是财商的一部分

第五课：富人的投资创造力 ​

富人创造投资机会，而不是等待机会：

  • 学会识别别人看不到的机会
  • 提高投资回报率，降低风险
  • 创造资产而不是购买资产
  • 投资需要三个E：Education（教育）、Experience（经验）、Excessive cash（充足现金）

第六课：为学习工作而不是为钱工作 ​

年轻时应优先考虑学什么而不是赚多少：

  • 学习销售、营销、沟通技能
  • 学习管理、领导、团队协作
  • 学习投资、财务、法律知识
  • 技能组合比单一技能更有价值

克服困难 ​

书中指出阻碍财富积累的五个障碍：

1. 恐惧心理 ​

害怕失去钱，不敢投资。但风险是机会的代价，学会管理风险而不是回避风险。

应对策略：

  • 从小额投资开始
  • 先学习再投资
  • 分散投资降低风险

2. 愤世嫉俗 ​

怀疑一切，认为投资是骗局、机会不存在。消极心态会错过真正的机会。

应对策略：

  • 保持开放心态
  • 分析而不是否定
  • 小范围尝试验证

3. 懒惰 ​

用忙碌掩盖思考的懒惰，逃避真正重要的事情。

应对策略：

  • 定期反思财务状况
  • 制定明确的财务目标
  • 行动比计划更重要

4. 不良习惯 ​

先支付别人（账单、债务），最后才考虑自己。

应对策略：

  • 先支付自己（投资、学习）
  • 用压力激发创造力
  • 建立储蓄和投资习惯

5. 自负 ​

不懂装懂，拒绝学习新知识。

应对策略：

  • 承认自己的不足
  • 向专业人士请教
  • 持续学习更新认知

开始行动的十个步骤 ​

1. 我需要一个超现实的理由 ​

找到内心深处的动力——你为什么想要财务自由？

  • 想要时间自由？
  • 想要照顾家人？
  • 想要环游世界？
  • 想要帮助他人？

2. 每天做出选择 ​

每天都要做财务决策：

  • 学习还是娱乐？
  • 储蓄还是消费？
  • 投资还是观望？

3. 慎重地选择朋友 ​

结交有财务智慧的朋友：

  • 向成功者学习
  • 避免消极影响
  • 分享投资机会

4. 掌握一种模式，然后再学习一种新的 ​

先精通一种投资方式，再扩展：

  • 股票 → 房产 → 企业
  • 逐步建立投资组合

5. 首先支付自己 ​

收入分配顺序：

收入 → 投资/储蓄 → 支出/账单
1

这会迫使你更努力工作，同时积累资产。

6. 给你的经纪人优厚的报酬 ​

好的顾问值得高报酬：

  • 房产经纪人
  • 财务顾问
  • 法律顾问

专业建议能帮你节省更多。

7. 做一个"印第安给予者" ​

投资要考虑回报周期：

  • 多久能收回投资？
  • 回收后资产还在吗？
  • 无风险回报是多少？

8. 用资产产生的钱购买奢侈品 ​

用被动收入购买奢侈品：

  • 资产收入 → 奢侈品
  • 而不是：工资 → 奢侈品

9. 对英雄的崇拜 ​

学习成功投资者的方法：

  • 巴菲特的价值投资
  • 索罗斯的对冲策略
  • 本地成功案例

10. 先予后取 ​

给予会带来回报：

  • 分享知识
  • 帮助他人
  • 建立人脉

财商的四个技能 ​

技能内容重要性
会计财务知识、读懂报表基础技能
投资让钱生钱的科学核心技能
了解市场供需关系、趋势判断机会识别
法律税务、公司结构、合同风险保护

我的思考与行动计划 ​

读完这本书，我开始反思自己的财务状况：

现状分析 ​

  • 收入来源单一（工资）
  • 没有真正的资产
  • 消费习惯需要改善
  • 财商知识严重不足

行动计划 ​

短期（1年内）：

  1. 记账 - 使用记账软件，了解自己的现金流
  2. 学习 - 系统学习理财知识，阅读相关书籍
  3. 储蓄 - 建立应急基金（3-6个月生活费）
  4. 尝试 - 开始小额投资尝试（指数基金）

中期（3年内）：

  1. 积累 - 持续投资，积累资产
  2. 开源 - 探索副业和被动收入来源
  3. 技能 - 提升财商四个技能
  4. 规划 - 制定详细的财务自由时间表

长期（10年内）：

  1. 目标 - 被动收入覆盖生活支出
  2. 资产 - 建立多元化的资产组合
  3. 传承 - 财商教育传承给下一代

总结 ​

这本书的核心价值不是教你具体的投资技巧，而是帮你建立正确的财富思维框架：

核心认知转变 ​

旧认知新认知
高收入 = 富人高资产 = 富人
房子 = 资产现金流决定资产属性
工作稳定 = 安全财务自由 = 安全
风险 = 危险风险 = 机会的代价
学习 = 学校教育学习 = 一生的功课

最终目标 ​

财务自由的本质是时间自由——不再为钱工作，而是让钱为你工作，你可以自由选择如何使用时间。

富人不是因为有钱才聪明，而是因为聪明才有钱。

财商教育是一生的功课，从今天开始行动。
