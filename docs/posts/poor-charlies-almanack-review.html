《穷查理宝典》读书笔记 - 构建你的思维模型武器库 ​

这本书我读了三遍。第一遍觉得是一个聪明老头的碎碎念，第二遍开始意识到那些"碎碎念"背后有一套严密的思维系统，第三遍才真正明白——这本书不是在教你投资，是在教你如何正确地思考。

查理·芒格，伯克希尔·哈撒韦的副董事长，巴菲特 60 年的搭档。但读这本书之前我对他几乎一无所知，毕竟他一直活在巴菲特的光环背后。读完才知道，巴菲特说"是查理让我从猩猩进化成了人"不是谦虚——芒格是那个真正搭建了伯克希尔投资哲学底层逻辑的人。

这本书不是芒格自己写的，是他的朋友彼得·考夫曼整理的演讲稿、文章和谈话。结构松散，但思想密度极高——几乎每一页都值得停下来想一会儿。

多元思维模型：不要只拿一把锤子 ​

芒格最核心的思想，就藏在他反复念叨的那句话里：

"手里只拿一把锤子的人，看什么都像钉子。"

这句话我最初以为是说专业人士的狭隘，后来发现不对——他说的是所有人。每个人都有一把"锤子"，就是自己最擅长或最熟悉的那个领域的思维方式：

你是什么人你的锤子
程序员用代码逻辑解释一切
经济学家用供需曲线解释一切
心理学家用童年创伤解释一切
医生用病理指标解释一切

而芒格的主张是：你应该掌握每个重要学科里最核心的两三个模型，然后把它们组合起来用。

他列出的关键学科和模型大致包括：

  • 数学：复利思维、概率论、决策树
  • 心理学：误判心理学（他自己总结了 25 种倾向）
  • 经济学：规模优势、对比优势
  • 物理学：临界质量、反馈回路
  • 生物学：自然选择的进化思维

你不必成为每个领域的专家，但你得知道那个领域里最重要的思考工具是什么。

🎯 我是怎么用的

  • 做技术选型时，不只从工程角度看（代码好不好写），也加一个经济学视角（边际成本会不会越来越高？）
  • 遇到问题时先问自己："我是不是在用老本行的套路硬套一个不同性质的问题？"
  • 刻意去读自己专业以外的书——心理学、生物学、历史——不是兴趣广泛，是思维模型需要原料

逆向思维：反过来想，总是反过来想 ​

芒格有一句名言，几乎成了他的人生标签：

"告诉我我会死在哪里，我就永远不去那个地方。"

这就是逆向思维的核心：与其想'怎么成功'，不如想'怎么失败然后避开'。

这个思维方式的厉害之处在于——正向思考往往太模糊，"怎么幸福""怎么赚钱"这种问题你很难给出一个可操作的答案。但反过来问就具体多了：

正向问题（难回答）逆向问题（可操作）
怎么才能幸福？什么会让人不幸福？——嫉妒、抱怨、自怜、不靠谱的伴侣。避开这些
怎么才能赚到钱？什么会让人破产？——过度杠杆、跟风投机、不承认错误。不做这些
怎么写出好代码？什么会导致烂代码？——没测试、没文档、不 Code Review。反过来做

我在用这个方法之后，最明显的变化是——做决策前我会先列一个"不可为清单"。不是因为我有自制力，而是想清楚了自己要避开什么，选择反而少了，决策反而快了。

人类误判心理学：你比自己以为的好骗得多 ​

这是全书我读得最慢、划笔记最多的一章。芒格总结出了 25 种让人做出错误判断的心理倾向，每一种都是一记闷棍——你读完会发现，你以为的理性决策，其实全是这些倾向在背后操纵。

我挑几个最让我警醒的：

1. 奖励和惩罚超级反应倾向 ​

"永远不要低估激励的力量。"

人会对激励做出反应——而且是强烈的、有时甚至扭曲的反应。绩效考核考什么，员工就做什么，哪怕那个指标和真正的价值没什么关系。联邦快递以前按时间付薪，夜班工人效率极低；改成按班次付薪后，效率暴增。

启示：永远先看清楚激励机制是什么，再判断一个人的行为。

2. 喜欢/热爱倾向 ​

我们会因为喜欢一个人而忽略他的错误，也会因为讨厌一个人而否定他的正确。这在投资里是最致命的——你觉得一家公司"酷"、CEO"有魅力"，就开始忽略财务报表上的红色信号。

启示：做判断时把人和事拆开。你可以喜欢一个人，但别让喜欢影响判断。

3. 避免不一致倾向 ​

人一旦公开说过某个观点，几乎就不可能改了——不是因为固执，是因为大脑把"改变观点"等同于"承认自己之前很蠢"。这也是为什么成年人几乎不可能在大事上改变立场。

启示：别在公开场合轻易表态。保留'我可能错了'的余地。

4. 自视过高倾向 ​

90% 的司机认为自己的驾驶技术高于平均水平——这在统计上是不可能的。我们在几乎所有方面都高估自己：能力、运气、道德水准。

启示：做重大决策前，强迫自己写出三个可能出错的地方。写不出来就是没想清楚。

完整的 25 种倾向我不逐一罗列了，但这一章的价值在于：它给了你一个检查清单。每次做完决策，对照着过一遍——我中了哪个倾向？

能力圈：知道自己不知道什么 ​

"知道自己不知道什么，比聪明更重要。"

芒格和巴菲特一辈子都在说这句话。他们的投资策略简单到不可思议：**只投自己真正理解的生意。**不理解的一律不碰——不管多热门、多少人赚了钱。

这就是能力圈的概念：

能力圈以内：你真正懂的东西。不是"听说过"、不是"有印象"。
能力圈边缘：你大概知道但不确定的东西。可以学习，但别在这里下重注。
能力圈以外：你完全不懂的东西。承认自己不懂，果断远离。

承认自己不懂，是一种被严重低估的能力。

我做程序员的时候，最怕面试官问到自己不会的技术。后来想通了——大方说"这个我不熟"比硬头皮瞎编强一百倍。芒格一辈子被问到过无数问题，他的标准回答之一是："我不知道。"然后就不说话了。

芒格的投资检查清单 ​

这部分我读的时候专门做了笔记，因为它的普适性远超投资领域。芒格做投资决策前会过一遍这个清单：

  1. 风险：最大的风险是什么？我真的理解这个风险吗？
  2. 能力：这是我能力圈之内的事吗？
  3. 数据：有什么事实是我忽略了或者不愿意面对的？
  4. 心理学：我现在的情绪（贪婪、恐惧、嫉妒）有没有影响判断？
  5. 逆向：反过来的情况可能是什么？它发生的概率是多少？

我把这个清单改造成了技术决策版：

芒格原版技术决策改编
最大的风险是什么？这个方案最坏会导致什么后果？
这是我能力圈之内的吗？我的团队能驾驭这个技术栈吗？
有什么事实被我忽略了？测试覆盖率、线上监控、回滚方案，都齐全吗？
我的情绪有没有影响？我选这个方案是因为它"最合适"还是因为"大家都在用"？
反过来的情况可能是什么？如果我们什么都不做，会怎样？

终身学习：聪明人没有不每天阅读的 ​

这是全书被引用最多的一句话：

"我这辈子遇到的聪明人，没有一个不每天阅读的——没有，一个都没有。"

芒格自己的阅读量惊人。他被称为"长着两条腿的书架"，80 多岁时依然每天阅读四五个小时。不是因为勤奋——因为阅读对他来说是获取思维模型最便宜的方式。

一本书几十块钱，换来的是另一个人穷尽一生思考的精华。还有什么投资比这个回报率更高？

更重要的是——不读书的人，只能从自己的经验中学习。而一个人的经验太有限了。你不可能亲自犯所有错误再吸取教训，但从书里你可以看到无数人犯过的错、走过的路。

诚实、正直与简单的普世智慧 ​

芒格反复强调一个观点：诚实不是道德选择，是最优策略。

因为诚实不需要记忆力。你说了谎，就得记住你说了什么谎、对谁说的、在什么情境下说的——这太累了。而说实话，你只需要记住事实本身。从信息存储的角度看，诚实是成本最低的方案。

他还提到一个"黄金法则"：只跟那些你愿意互换位置的人做生意。 如果你不愿意站在对方的角度承担后果，那就说明这个交易本身有问题。

芒格哲学与七个习惯的内在共鸣 ​

读这本书的时候我强烈地感觉到——芒格的很多理念和史蒂芬·柯维的"七个习惯"是相通的。

芒格理念对应七个习惯
逆向思维以终为始（从终点倒推现在的行动）
能力圈要事第一（把精力放在你真正能影响的事上）
激励倾向双赢思维（设计规则让双方利益一致）
终身学习不断更新（磨刀不误砍柴工）

这让我确信——真正重要的智慧在不同的人那里会以不同的语言表达出来，但内核是相通的。

我的"不可为清单"与思维模型实践 ​

读完这本书之后，我在 Notion 里建了一个页面，叫"不可为清单"。参考芒格的逆向思维：

投资与财务

  • [ ] 不投自己不理解的东西（不管涨了多少）
  • [ ] 不加杠杆
  • [ ] 不在情绪激动时做财务决策

工作与技术

  • [ ] 不因为"别人都在用"就选一个技术栈
  • [ ] 不做没有回滚方案的线上变更
  • [ ] 不在没理解需求时就开始写代码

生活与学习

  • [ ] 不连续三天不读书
  • [ ] 不在公开场合对不确定的事做绝对表态
  • [ ] 不因为一个人"看着顺眼"就忽略他逻辑上的问题

这个清单我会每季度更新一次。重点不是写得对，是真的用它。
