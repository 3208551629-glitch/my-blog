《非暴力沟通》读书笔记 - 90% 的矛盾，来自不会说话 ​

我以前以为"暴力沟通"指的是吵架、骂人、冷嘲热讽。读完这本书才发现——大部分时候我自以为在"正常说话"，其实句句都是暴力。

这本书的作者马歇尔·卢森堡是个美国人，但他做的事很特别——他 60 年代去中东调停巴以冲突，去卢旺达帮部落化解种族仇恨，去监狱帮狱警和囚犯对话。他不是外交官，就是个心理学家。他用的就是这套"非暴力沟通"。

冲突调解大师的经验浓缩成了四个步骤。但不夸张地说，只要你真的把其中任何一步用到日常生活里，你的人际关系就会开始变化。

暴力的根源：评判、比较、推卸责任 ​

在进入方法之前，卢森堡先说明了什么叫做"暴力"。

"如果两个人互不理解，话语本身就是一堵墙。你永远不知道，你随口说出的哪句话会成为别人心里的一根刺。"

他说的"暴力"不只是拳脚。任何让对方感觉自己"错了""不够好""应该被指责"的表达，都是暴力。

最常见的暴力来源有几个：

评判：把事实和主观判断混在一起说。"你迟到了三次"是事实，"你这个人不靠谱"是评判。我们几乎每句话都在暗暗地做评判。

比较："你看隔壁老王家的孩子""你看别的团队怎么做的"——比较本身就是一种隐形攻击。被比较的人不会因此更努力，只会因此更挫败。

推卸责任："我也不想发火，但你那样说话谁受得了？"——这句话的意思是我不用为我的情绪负责，是"你让我"生气的。

强加要求："你必须……""你应该……"——把自己的期望包装成对方必须遵守的规则。

读完这章我背后全是冷汗。因为这里面的每一条——每一天我都在犯。

非暴力沟通四步法 ​

这是全书的核心操作手册。四步形成一个完整的表达链条：

观察 → 感受 → 需要 → 请求
1

每一步都值得拆开细聊。

第一步：观察而不评判 —— 说事实，不加标签 ​

这是最基础也最难的一步。因为我们的大脑默认就是"观察 + 评判"打包输出的。你在脑子里已经不自觉地加了一个"对/错""好/坏""应该/不应该"的标签。

❌ 带评判的表达✅ 只描述观察
你这个人太马虎了你这个月三次提交都没写过测试
他变得越来越懒了他上周连续五天都过了十点才起床
这个布告栏太乱了吧布告栏上有三张过期两周的通知
你怎么总是迟到这一周你有三天是九点半以后到的

区别在哪？评判让对方感觉被攻击，他会立刻进入防御模式。观察只陈述事实，对方能在没有情绪干扰的情况下回应对事实。

"不带评论的观察，是人类智力的最高形式。"——这是卢森堡引用的印度哲学家克里希那穆提的一句话。

我刚读到这里的时候觉得这太理想化了——怎么可能说话不带评判？但练了几次就发现：你不需要永远不带评判，只需要在关键的、容易起冲突的时刻，先停下来把评判摘掉，再用纯观察开头。

就这一步，我已经避免了很多次本可以吵起来的对话。

第二步：表达感受 —— 区分感受与想法 ​

中国人特别不擅长这个。我们的情绪词汇库很小——"开心""难过""生气""烦"——区区几个词，远远不足以描述内心真实的体验。

卢森堡在书里附了一张"感受词汇表"，分成"需要被满足时"和"需要未被满足时"两类，每类各列了几十个词：

需要被满足时的感受需要未被满足时的感受
感激、欣慰、安心、自信、兴奋、满足、放心、充满希望……焦虑、孤单、疲惫、失望、沮丧、困惑、不安、无力……

更重要的是——要区分"感受"和"想法"。

❌ 这是想法，不是感受✅ 这才是感受
我觉得你不在乎我我很孤单
我觉得这不公平我感到愤怒
我觉得自己被忽视了我很难过
我觉得这样做不对我很不安

"我觉得你不在乎我"表面上是感受，实际上是一个对他人的判断。"你不在乎我"——这是在说对方有问题，不是在说自己怎么了。对方听到这句话，第一反应一定是：我怎么不在乎你了？你看我做了什么什么——辩解模式启动。

但如果你说的是"我很孤单"，对方可能就会问：为什么觉得孤单？你需要什么？——对话的方向完全不同了。

🎯 我的实践：在对话中强制自己使用"我感到……"而不是"我觉得你……"。前者通向连接，后者通向冲突。

第三步：说出需要 —— 情绪背后的真相 ​

"每一个'不'的背后，都藏着一个未被满足的'需要'。每一个愤怒的背后，都有一个未被触碰的脆弱。"

这是全书最颠覆我认知的一句话。

我们表达愤怒的方式通常是："你怎么能这样！"——这是在攻击别人。但如果跟着非暴力沟通的框架往下挖，愤怒其实只是一个信号——它在提示你：你有某个核心需要没有被满足。

表面的情绪和指责真正的需要
"你从来不回我消息！" →我需要被在乎
"老板老是改需求！" →我需要稳定的预期
"同事太吵了！" →我需要一个能专注的环境
"孩子不听话！" →我需要秩序感和尊重

一旦你发现了真正的需要，对话的焦点就从"你这个人怎么样"变成了"我们怎么满足这个需要"。 前者是对抗，后者是合作。

卢森堡说，人类所有行为都是在试图满足某种需要。哪怕是最让人反感的行为——迟到、拖延、撒谎、发脾气——背后通常都有一个你没有看到的"需要"。

这并不意味着纵容。但理解了需要之后，你处理问题的方式会完全不同：

  • 不理解需要时：你怎么又迟到了？扣工资！
  • 理解需要后：我发现你最近经常迟到，是在时间安排上遇到什么困难了吗？

前者推开了人，后者打开了对话。

第四步：提出请求 —— 具体、正向、可操作 ​

前三步已经完成了 80%。最后一步是提出请求——不是命令，是请求。

好请求的三个标准：

1. 具体："你以后对我好一点"——什么叫"好一点"？对方没法执行。改成："下次如果有事不能按时到，能提前一小时告诉我吗？"——对方知道该做什么。

2. 正向（说你要什么，不说你不要什么）："你别老玩手机"——OK，我不玩手机，那我干什么？改成："我希望晚上一起吃饭的时候，我们能聊聊天，不刷手机。"

3. 可操作：请求必须是对方能做到的具体行动。"我希望你尊重我"——太大了，不知道怎么执行。改成："当我说话的时候，我希望你能先让我把话说完再回应。"

❌ 模糊的、负向的"请求"✅ 具体的、正向的请求
你以后别这样了下次能先跟我商量一下再做决定吗？
你能不能在乎一点我的感受？我说话的时候，你能先听完再给建议吗？
你别老是加班我希望每周至少有三天我们能一起吃晚饭

最妙的一点是——请求和命令的区别不在于措辞，在于对方说"不"时你的反应。 如果你能接受对方的拒绝，那它就是一个真正的请求。如果对方拒绝你就生气了，那说明你刚才说的不是请求，是命令。

全身心倾听：用四个步骤听懂对方 ​

非暴力沟通不只是怎么表达，也是怎么听。当对方在说话的时候——尤其是对方在表达负面情绪的时候——我们也用这四个步骤去"接住"对方：

  • 你听到了什么观察？
  • 对方的感受是什么？
  • 对方的需要是什么？
  • 对方在请求什么？

不需要替对方解决问题，只需要帮对方理清他自己。把上面这四个问题用自己的话复述给对方听——"听起来你觉得很难过，因为你的努力没有被看到，你需要被认可，是吗？"对方会感觉你真的在试着理解他——因为这个世界上大部分人根本不在听。

用非暴力沟通对待自己 ​

这是书中很打动我的一章——大多数人以为非暴力沟通是用来跟别人说话的，但最大的暴力对象，往往是我们自己。

我们在心里骂自己的那些话："我怎么这么蠢""别人都做得比我好""我又搞砸了"——如果把这种话施加在另一个人身上，你就是在做赤裸裸的精神虐待。

卢森堡说，对自己也用非暴力沟通的四步：

  • 观察：我刚才做了什么事？（事实，不加评判）
  • 感受：我现在是什么感觉？（不是"我很差"，是"我感到挫败"）
  • 需要：我的什么需要没有被满足？（是"进步的需要"，不是"完美的需要"）
  • 请求：我接下来可以做什么？（具体的、可行的行动）

用这个框架对待自己，你就从"自我打击"切换成了"自我关怀"。 同样的错误，前者让你不敢再试，后者让你愿意再试一次。

愤怒管理：从"你让我生气"到"我需要……" ​

"生气，不是因为对方做了什么。生气，是因为你的某个需要没有被满足，而你在用指责来表达它。"

卢森堡并不说"不要生气"。他承认愤怒是真实存在的情绪。但他说——愤怒的表达有两条路：

暴力之路：愤怒 → 指责 → 冲突升级 → 关系受损 非暴力之路：愤怒 → 停下来 → 问自己"我需要什么" → 表达需要而非指责

走第二条路的关键是那个"停下来"。在你想骂人的那一秒，给自己一个停顿。哪怕只是深吸一口气。在那个停顿里，做一件事：找到那个未被满足的需要。

这里和卡尼曼的"系统 1 / 系统 2"产生了一个非常妙的联结——愤怒时的指责冲动是系统 1 在说话（快、自动、情绪化），而停下来寻找需要是唤醒系统 2（慢、理性、有意识）。

非暴力沟通在团队协作中的应用 ​

作为一个程序员，我特别关注怎么把这套方法用到工作中。技术团队的沟通质量差异惊人——有的团队看似每天都聊得热火朝天，仔细一听全是在彼此驳回、彼此质疑、彼此防御。有的团队话不多，但每次沟通都直接有效。

非暴力沟通在技术场景下特别有用的几个点：

Code Review 时

  • ❌ "这个函数写得太长了，不好维护"（评判）
  • ✅ "这个函数当前有 120 行。我担心如果以后需要修改这里，错误排查会比较耗时。能不能把它拆成两到三个小函数？"（观察 + 感受 + 需要 + 请求）

需求讨论时

  • ❌ "这个需求不靠谱"（评判，对方会立刻防御）
  • ✅ "按照当前的人力估算，这个需求大约需要六周。我担心会影响另外两个已经承诺的交付。我们是不是可以把这个大的拆成两阶段，先交付最核心的部分？"（观察 + 感受 + 需要 + 请求）

给反馈时

  • ❌ "你进度太慢了"（评判）
  • ✅ "这个任务原计划上周五完成，现在是周三。我有点担心项目整体的排期。你看还需要什么支持来完成它？"（观察 + 感受 + 需要 + 请求）

同样的诉求，换了非暴力的表达，对方的反应是天差地别的。 不仅仅是因为措辞"好听"——是因为你明确告诉了对方：发生了什么事实、你感觉怎样、你要什么、你要他怎么配合。他不需要猜你，你也给了他清晰可执行的下一步。

我的 30 天沟通日志实践 ​

读完这本书之后我做了个小实验：30 天，每天睡前花两分钟记录一次当天的沟通：

  1. 今天有没有一次沟通，我说完就后悔了？
  2. 如果重来一次，用四步法可以怎么说？
  3. 今天有没有一次沟通，对方在指责我，但我听出了他背后的"需要"？

第一周惨不忍睹——几乎天天都有后悔的沟通。但从第二周开始，因为每天都要记录，我开始在"说出口之前"多停顿一秒。 就是那一秒的停顿，让我从"自动化反应"切到了"有意识选择"。

到第四周，回头看第一周的记录，感觉像看另一个人的日记。
