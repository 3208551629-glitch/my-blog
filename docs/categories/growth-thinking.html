🎯 成长思考 ​

关于职业发展、学习方法、效率提升的思考，记录个人成长历程。

学习规划 ​

我的 2026 年学习计划 ​

新的一年，给自己定下学习目标。技术学习包括 Vue 3 生态深入、TypeScript 类型编程、Vite/Webpack 原理、Nest.js 框架、PostgreSQL/Redis、Docker 容器化、AI 应用开发、Rust 入门。读书计划涵盖技术书籍和非技术书籍。项目实践包括博客系统优化、工具库封装、开源贡献。

读书笔记 ​

《刻意练习》读书笔记 ​

推翻一万小时定律的经典之作。刻意练习的四个标准——明确目标、极度专注、即时反馈、走出舒适区——才是从普通到卓越的真正路径。心理表征理论解释了高手与普通人的本质差异。文章将刻意练习方法应用到编程学习中，提出"目标-反馈-调整"的实战框架。

《非暴力沟通》读书笔记 ​

卢森堡博士的全球冲突调解经典。核心四步法——观察而不评判、表达感受而非想法、说出需要而非指责、提出请求而非命令——看似简单，实则需要反复练习。文章包含大量沟通场景的对比实例、技术团队 Code Review 和需求讨论中的应用，以及 30 天沟通日志实践。

《高效能人士的七个习惯》读书笔记 ​

柯维把人的成长拆成依赖→独立→互赖三个阶段。七个习惯不是七个独立技巧，是一条完整的成长链。文章逐一深挖每个习惯的核心机制——关注圈与影响圈、以终为始、四象限时间管理、双赢思维、同理心倾听——并给出每日/每周/每月的实践检查体系。

《思考，快与慢》读书笔记 ​

诺贝尔经济学奖得主卡尼曼的认知心理学经典。系统1和系统2的运作机制解释了为什么人不是理性的。文章深度解读十几种认知偏差——可得性、锚定、过度自信、损失厌恶、确认偏误等——并将它们映射到编程和技术决策的日常场景中，附决策自检清单。

《穷查理宝典》读书笔记 ​

查理·芒格的智慧合集。核心内容包括多元思维模型、逆向思维、25种人类误判心理学倾向、能力圈概念。文章将芒格的投资检查清单改造为技术决策版，并分析了芒格哲学与七个习惯的内在共鸣。附个人"不可为清单"实践。

《从0到1》读书笔记 ​

彼得·蒂尔的经典之作，探讨如何创造新事物而非复制已有模式。核心观点：竞争是失败者的游戏，真正有价值的企业必须实现从0到1的跨越。书中详细阐述了垄断的力量、幂次法则、秘密的价值、初创企业的七大问题。这本书改变了我对创业、竞争和未来的看法。

《穷爸爸富爸爸》读书笔记 ​

这本书改变了我对金钱和财富的认知方式。核心观点是区分资产与负债：资产能把钱放进你口袋，负债把钱从你口袋拿走。文章详细分析了两个爸爸的不同思维模式、现金流差异、六课核心内容、克服困难的五个障碍，以及我个人的财务自由行动计划。

核心认知转变：

旧认知新认知
高收入 = 富人高资产 = 富人
房子 = 资产现金流决定资产属性
工作稳定 = 安全财务自由 = 安全
风险 = 危险风险 = 机会的代价
