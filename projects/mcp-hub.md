## 项目简介

MCP Hub 是一个 MCP (Model Context Protocol) 服务器管理和编排仪表板。

统一管理 MCP 服务器配置，监控服务器状态，提供直观的 Web 界面进行服务器生命周期管理。

## 功能特性

- **MCP 服务器统一管理**：集中管理所有 MCP 服务器配置
- **服务器状态监控**：实时监控服务器运行状态
- **API Token 认证**：安全的访问控制
- **服务器生命周期管理**：启动、停止、重启服务器
- **Next.js 仪表板界面**：现代化的 Web 管理界面
