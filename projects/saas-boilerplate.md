## 项目简介

SaaS 项目脚手架 — Next.js + Stripe + Prisma 全栈模板。

## 功能特性

- NextAuth v5 认证
- Stripe 支付集成
- AI 聊天功能
- 订阅管理
- Prisma ORM + SQLite

## 技术栈

- **Next.js**
- **React 19**
- **TypeScript**
- **Prisma**
- **Stripe**
- **NextAuth v5**

