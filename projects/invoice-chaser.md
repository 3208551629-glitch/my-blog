## 项目简介

发票追踪工具 — AI 自动写催款邮件并定时发送。

## 功能特性

- AI 自动生成催款邮件
- 定时发送任务
- 发票状态追踪
- 邮件模板管理
- FastAPI + Vue3 全栈

## 技术栈

- **FastAPI**
- **Vue 3**
- **DeepSeek API**
- **Celery**

## 项目状态

- **状态**: 稳定维护中
- **分类**: SaaS/Web


## 快速开始

### 安装

```bash
pip install -r requirements.txt && npm install
```

### 运行

```bash
npm install && npm run dev
```
