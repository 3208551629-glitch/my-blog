# 我的 2026 年学习计划

新的一年，给自己定下一些学习目标，希望能在技术上有所突破。

## 技术学习

### 前端深入

- **Vue 3 生态** - 深入理解响应式原理，掌握 Pinia、Vue Router
- **TypeScript** - 提升类型编程能力，学习高级类型技巧
- **构建工具** - 深入 Vite、Webpack 原理
- **CSS** - 掌握 Tailwind CSS，学习 CSS-in-JS 方案

### 后端拓展

- **Node.js** - 学习 Nest.js 框架
- **数据库** - 深入 PostgreSQL，学习 Redis
- **Docker** - 容器化部署实践

### 新技术探索

- **AI 应用开发** - 学习 LLM API 集成
- **Rust** - 入门学习，理解内存安全
- **WebAssembly** - 了解应用场景

## 读书计划

### 技术书籍

- 《JavaScript 高级程序设计》- 重读经典
- 《设计模式》- 理解常用模式
- 《代码整洁之道》- 提升代码质量

### 非技术书籍

- 《深度工作》- 提升专注力
- 《系统之美》- 理解系统思维

## 项目实践

### 个人项目

1. **博客系统** - 持续优化，添加评论、搜索功能
2. **工具库** - 封装常用工具函数，发布 npm 包
3. **开源贡献** - 参与感兴趣的开源项目

### 技术写作

- 每周至少一篇技术文章
- 记录学习笔记和踩坑经验
- 整理知识体系

## 健康生活

- 每周运动 3 次以上
- 保持规律作息
- 减少无效社交

## 总结

计划赶不上变化，但有了目标就有了方向。希望 2026 年能成为一个更好的自己！
